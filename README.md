# 和音練習室（Harmony Lab）

在手機瀏覽器練習唱流行曲和音的單頁應用。內含六首以香港流行曲風格原創的短曲，逐句示範旋律與和音聲部，並用麥克風即時評分。

網址：<https://alice-creator-lab.github.io/harmony-lab/>

## 使用方式

1. 選擇曲目與句子（「全曲」只供聆聽，評分要選單句）。
2. 按「聽示範」，聽一次旋律與和音同時進行的效果；可用「聲部」開關只聽和音，或以 0.75／0.9 倍速慢聽。
3. 按「跟我唱」，四拍預備後伴奏與示範停止，你唱該句和音。畫面會顯示你的即時音高軌跡。
4. 唱完自動評分：命中數、平均偏差（音分）、偏高或偏低、穩定度，以及逐音偏差。

## 練習次序

曲目按難度排列：

1. **舊站台** — 三度上和音，最基礎的「貼着旋律上方」。
2. **半頁信** — 三度下和音，練習在旋律下方找音。
3. **夏夜電車** — 五度上和音，音程較寬，需要記住跳躍。
4. **天台看星** — 八度上和音，先建立「同一旋律另一個八度」的感覺。
5. **旺角黃昏** — 三度上，速度較快、跳進較多。
6. **離島渡輪** — 六度下和音，屬中低音域的和音聲部。

建議先把一首的三度上和音唱到命中率八成以上，再換下一首；和音訓練真正的難點是「一邊聽旋律、一邊保持自己的音」，所以每一首都值得重複。

## 評分方式

- 麥克風以 YIN 演算法追蹤音高，每約 21 毫秒取樣一次。
- 每一音取時間窗內音高的中位數，與目標和音比較，得出音分偏差（100 音分等於一個半音）。
- 偏差在容差之內（預設 50 音分）即為命中；「穩定度」是各音偏差的中位絕對差，代表聲音是否穩定而不是忽高忽低。
- 平均偏差超過一個全音時，畫面會提示「可能唱了旋律或其他聲部」。

## 重要的操作條件

- **不要戴耳機時，評分期間全程靜音**：示範播放完才開始計分，所以伴奏不會滲入麥克風。
- 若想在唱歌時聽伴奏，請在「進階」開啟**耳機模式**並戴上耳機；否則伴奏會被麥克風收到而影響分數。
- 麥克風需要 HTTPS 或 `localhost`。手機請用上方網址，不要用 `file://` 開啟。
- 環境越安靜、手機距離口部約二十公分，分數越穩定。

## 匯入自訂曲目

「進階」→「匯入自訂曲目」可載入一個 JSON 檔（可為單一物件或陣列），曲目會存在瀏覽器本機，並加入清單。

```json
{
  "id": "mine",
  "title": "我的練習",
  "tempo": 80,
  "tonic": 60,
  "mode": "major",
  "har": { "step": 2, "dir": 1 },
  "lines": [
    { "deg": "3/1 5/1 6/1 5/1 3/2 1/2", "lyr": "第一句歌詞", "chords": ["C", "G"] }
  ]
}
```

- `tonic`：主音 MIDI 音高（中央 C 為 60），也可寫音名如 `"C"`、`"G"`。
- `mode`：`major` 或 `minor`。
- `har`：和音規則。`step` 是音階級數（2＝三度、3＝四度、4＝五度、5＝六度、7＝八度），`dir` 為 `1`（上方）或 `-1`（下方）。每一句可用 `har` 欄位覆寫。
- `deg`：簡譜音級序列，格式「音級/拍數」。`1` 至 `7` 為音階音級，可加 `#`、`b`；`'` 升八度、`,` 降八度；`0` 為休止。每句建議剛好八拍。
- `chords`：該句兩個和弦，各佔半句，只影響伴奏。

曲目資料只存在你的裝置，不會上傳。若把有版權的歌曲旋律寫成 `deg` 序列，請自行確保使用方式合法；本專案內建的六首曲目皆為原創，不含任何現成歌曲的旋律或錄音。

## 開發與測試

```
python3 -m http.server 8831 --bind 127.0.0.1     # 本機預覽
node tools/gen-harmony.mjs platform 0 0.46 /tmp/h.wav har   # 合成和音聲部作測試輸入
node tools/mic-test.mjs /tmp/h.wav 9841 "http://127.0.0.1:8831/?count=0&nosw=1" shot.png
node tools/flow-test.mjs 9851 "http://127.0.0.1:8831/?count=0&nosw=1" shot.png
```

`tools/mic-test.mjs` 以 Chrome 的假音效裝置把合成好的和音餵入麥克風，跑完整個評分流程，用來驗證逐音命中是否正確（實測：和音輸入 9／9 命中、平均偏差 0 音分；餵入旋律則 0／9 命中、偏差約 −300 至 −400 音分）。`tools/flow-test.mjs` 檢查手機尺寸排版、示範播放的音訊節點是否在停止後全部釋放、全曲是否禁止評分、以及自訂曲目匯入。

`?count=0` 關閉四拍預備，`?nosw=1` 不註冊 Service Worker，兩者只供測試使用。

## 技術

- 單一 `index.html`（無外部依賴）加 `sw.js` 離線快取，純前端合成（Web Audio），不載入任何音檔。
- 音高偵測：YIN（差函數＋累積均值正規化＋拋物線插值），視窗 1024 取樣，低音下限約 90 Hz。
- 伴奏由和弦即時合成（低音、墊音、八分音符琶音）；引導音以正弦為基底、只保留少量低次諧波，加上輕微抖音，避免高頻刺耳。總輸出經 5.6 kHz 低通，峰值約 0.43，不會削波。
- `tools/tone-test.mjs` 會離線渲染整句並量測峰值、頻譜重心與 4 kHz 以上能量佔比，用來確認音色不會過於尖銳（現時 4 kHz 以上能量為 0 %）。
- 版本號顯示在標題右側，更新後如仍見舊畫面，請重新載入。

## 已知限制

- 只評音高，不評咬字、氣息或母音。
- 手機麥克風有 50 至 150 毫秒延遲；收音較差時個別音會被判為「未唱到」。
- iOS Safari 需在使用者手勢後才能啟動音訊，本應用在按下按鈕時啟動，第一次按可能稍有延遲。
